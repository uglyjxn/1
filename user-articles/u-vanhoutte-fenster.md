# Vanhoutte-Fenster
Kategorie: Technik · Entwurf

Das **Vanhoutte-Fenster** ist ein Bereich, in dem ein makroskopisches Objekt trotz Masse kohärent bleibt, was den [[Quantentunnel (Hintergrund)|Quantentunnel]] ermöglicht. Es wurde 2217 von der belgischen Physikerin [[Odile Vanhoutte]] in Leuven bei Experimenten an Bose-Einstein-Kondensaten beschrieben. 2228 bauten Sonderprojekte die ersten Prototypen. Der Name wird im Fachjargon oft zu „V-Fenster“ gekürzt.
