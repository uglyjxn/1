# Henriette Marais-Okoye
Kategorie: Person · Entwurf

**Henriette Marais-Okoye** führte 2074 die EU-Delegation bei den Verhandlungen zum [[Vertrag von Shackleton]]. Juristin aus Brüssel, ihr Doppelname steht für die gemischte Herkunft der Gründergeneration. Sie gilt als Verfasserin großer Teile der Solaren Grundordnung (2076), die an das europäische System der Kodifikation anknüpft.
