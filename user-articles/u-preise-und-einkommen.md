# Preise und Einkommen
Kategorie: Wirtschaft · Kanon, Details im Entwurf

Die Preise passen zum heutigen Stand in Europa, mit weniger Inflation (≈ 0,5–1 % im Jahr). Bei einer Wirtschaftsleistung von ≈ 80.000 Cr je Kopf entspricht 1 Cr etwa 0,5 € heutiger Kaufkraft.

| Posten (Erde) | Preis |
|---|---|
| Brot | 1,80 Cr |
| Mittagessen | 8 Cr |
| Miete 2-Zimmer-Wohnung | 1.400 Cr/Monat |
| Monatskarte | 55 Cr |
| Passage zum Nachbarstern | 3.000–15.000 Cr |

| Beruf (Erde) | Monatsgehalt |
|---|---|
| Facharbeiter | ≈ 4.500 Cr |
| Pilot | ≈ 9.000 Cr |
| Richter | ≈ 12.000 Cr |
| Dockarbeiter (mit Strahlenzulage) | ≈ 5.200 Cr |

In Randkolonien sind die Löhne brutto höher, die Kaufkraft niedriger. Preise sind lokal; der Kurierpreisindex (Ceres-Index) wird nur per Schiff aktualisiert, Händler nutzen Terminverträge und Preisgleitklauseln. Siehe [[Wirtschaft der Solarrepublik]].
